SRP VPN Connect Documentation

Step-by-step guides for the VPN protocols in SRP VPN Connect for iPhone, iPad and Android, from setting up the server to connecting, testing and fixing problems. On Android the app has WaterWall, SSTP, SoftEther VPN, SSL VPN, SSH VPN, OpenVPN and WireGuard so far; the other protocols are on iPhone and iPad.

WaterWallThe app's default protocol: profiles, chains, options and the scenarios we tested. SSTPMicrosoft's VPN over HTTPS, with our MikroTik, Windows and SoftEther test servers. SoftEther VPNSoftEther's own protocol: the server on Ubuntu, every login method, UDP acceleration, NAT traversal and proxies. SSL VPNAnyConnect with ocserv on Ubuntu: password and certificate logins, DTLS, split tunnel, and resuming the session. SSH VPNA VPN over an ordinary OpenSSH server: a user that may only forward TCP, a host key to pin, and an optional relay for UDP. OpenVPNOpenVPN 2.6 on Ubuntu with .ovpn profiles: certificate and password logins, UDP and TCP, and stunnel on port 443 with Let's Encrypt. WireGuardWireGuard on Ubuntu with a file for each phone: the handshake check, a split tunnel, reconnects and sleep. Future protocolsAdded only after their real tests are finished.

How these guides are written

Every test page describes something we actually ran on our own servers and phones. Commands, settings and results come from the records of those tests. When a detail was not recorded, the page says so instead of guessing.

Real server names, addresses, passwords and keys are replaced by placeholders in angle brackets, for example <SERVER_HOST> or <UUID>. Replace them with your own values.

Status labels

Each scenario carries one label that matches the evidence we have:

LabelMeaning
VERIFIED — TESTED SUCCESSFULLYWe ran it and it worked.
TESTED — FAILEDWe ran it and it did not work. The page explains what happened.
TESTED — PARTIALLY WORKINGWe ran it and only part of it worked.
NOT VERIFIEDSome information exists, but not enough evidence to call it tested.
PLANNED — NOT TESTEDA future scenario. It is not a finished guide.

Order of work

  1. WaterWall: guides, test scenarios and the Android results.
  2. SSTP: guides and test results for both phones.
  3. SoftEther VPN: guides and test results for both phones.
  4. SSL VPN: guides and test results for both phones against ocserv (AnyConnect); F5 BIG-IP and GlobalProtect are in the app but untested.
  5. SSH VPN: guides and test results for both phones against OpenSSH, with the UDP relay.
  6. OpenVPN: guides and test results for both phones against OpenVPN 2.6, with stunnel.
  7. WireGuard: guides and test results for both phones against WireGuard on Ubuntu 24.04.
  8. Other protocols: only after their tests are finished and reviewed.
