Requirements

WaterWall needs two sides: the app on your iPhone, iPad or Android phone, and a WaterWall server that you run yourself. This page lists what each side needs and the exact versions we tested with.

On the phone

iPhone or iPad

  • iOS or iPadOS 15.0 or later. This is the oldest system the app is built for.
  • SRP VPN Connect. It is distributed through TestFlight; see Installation.
  • Permission to add a VPN configuration. iOS asks for it the first time you connect.

Android

  • Android 8.0 (API level 26) or later, on a 64-bit ARM device (arm64-v8a). These are the oldest system and the only processor type the app is built for. We tested it with Android 16 and 17; see what we tested.
  • SRP VPN Connect. It is not in a store yet, so you build the APK from the source; see Installation.
  • Permission to set up a VPN connection. Android shows a Connection request the first time you connect.

The app already contains WaterWall, so nothing else needs to be installed on the phone.

On the server

  • A Linux server you control, with a public IP address and root access over SSH.
  • WaterWall. Our server runs version 1.5.2 from the radkesvat/WaterWall project plus the changes in the SRP VPN Connect repository, and every result on this site was measured against that program. Installation shows how to build it, and how to install the official 1.5.2 release, which we did not test.
  • Open ports in the server firewall for each configuration you run: TCP for most chains, UDP for QUIC, KCP and WireGuard.
  • A domain name pointing at the server, if you use the TLS chains. The certificate comes from Let's Encrypt, which also needs TCP port 80 open for renewals.
Plain-English terms
Chain
WaterWall builds a connection from small parts called nodes, joined in order. For example: listen on TCP, then TLS, then VLESS, then connect to the internet.
Port
A number on the server that one configuration listens on, such as 18443.

Before you continue

Checklist
  • You can log in to your server as root with SSH.
  • You know your server's public IP address. If you will use TLS, you also have a domain name pointing at it.
  • You have an iPhone or iPad with iOS 15 or later and the TestFlight app, or an Android device or emulator with Android 8.0 or later and a computer to build the APK on.
