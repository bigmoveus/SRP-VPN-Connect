WaterWall

WaterWall is an open-source tunneling program. SRP VPN Connect contains a WaterWall client, and you run a WaterWall server. This section shows how to set up both sides the way we tested them.

What WaterWall is

WaterWall is a networking core written by the radkesvat project. Instead of offering one fixed VPN protocol, it gives you small building blocks called nodes: one listens on a port, one adds TLS, one speaks VLESS, one connects to the internet, and so on. You join nodes into a chain, and the chain decides what your connection looks like on the network.

The official WaterWall documentation, which explains every node in detail, is at radkesvat.github.io/WaterWall-Docs. This site does not repeat it; it explains how WaterWall works with SRP VPN Connect.

How SRP VPN Connect uses WaterWall

A connection has two halves that must match:

  • On the phone, you choose the layers in the app, for example VLESS inside TLS. The app builds the client chain from your choices; you do not write client files by hand.
  • On the server, you write a configuration file with the matching server chain, for example TLS then VLESS, listening on a port.

Websites and services

The phone sends its traffic into the system's VPN. WaterWall in the app wraps it in the layers you chose and sends it to your server. The server unwraps the same layers in reverse order and connects to the real destination.

The rule that matters most The layers in the app and on the server must match, in the same order, on the same port. If the app uses VLESS + TLS and the server port runs Trojan + TLS, the connection fails. Each scenario page shows both halves side by side.
