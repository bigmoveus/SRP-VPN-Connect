Auto Switch to another profile of the same server

Checks that Auto Switch moves to another profile of the same server when the chosen one cannot connect.

VERIFIED — TESTED SUCCESSFULLY  Tested on 3 November 2026 on the current app build against WaterWall 1.5.2 plus the changes in the SRP VPN Connect repository (code at commit 671f3fbb).

Result

OutcomePassed: every check succeeded.

HTTPS checks through the tunnelPing: 184 ms; Ping: 153 ms

What the test does

  1. The test makes two profiles for the same server: the chosen one points at port 9, where nothing answers, and a second one has the working port.
  2. The chosen profile uses Auto Reconnect on and Retry Times 3.
  3. The test connects with the chosen profile.
  4. The connection must come up within 30 seconds on the second profile, and pass the app's HTTPS check twice.

Passes when the tunnel reports the second profile as active, both checks succeed, and the tunnel counted packets on its outer connection.

Test setup

The profile used the chain of the VLESS + TLS scenario, with the same server copy and profile settings, except the options the steps above change.

PhoneiPhone 12 with iOS 27.2 (build 24B119), on Wi-Fi
AppSRP VPN Connect 1.2.0 (build 33), a Debug build of commit a03a8bc2, installed by Xcode for the test. TestFlight build 33 is commit 7e1b6c42; the two commits after it change only WaterWall's speed test server, which the app does not build, and a description file
Server programWaterWall 1.5.2 plus the changes in the SRP VPN Connect repository (code at commit 671f3fbb), built from source as described in Installation: the same program as our permanent service, run as a test copy on port 4097
Server DNS lookups2 tries, WaterWall's default; the test copy's core.json does not set it
TrafficAn HTTPS test server on the same machine, port 28483
NetworkOur office broadband line, over the public internet

Gaps and limits

  • The phone did not really sleep, and WaterWall inside the app did not really crash: a Debug build of the app accepts test commands that make the tunnel act as if it had. Stopping the server is real.
  • Each step ran once, on one phone and one network.
