What the test does

  1. The profile uses Auto Reconnect on and Retry Times 2.
  2. The test connects. The test harness then stops the WaterWall copy on the server.
  3. The app must notice within 75 seconds that the connection no longer works.
  4. The harness starts the server copy again; the connection must be back within 45 seconds.
  5. The test runs the app's HTTPS check and 90 seconds of downloads and UDP echo exchange, then disconnects.

Passes when the app notices the failure, reconnects in time, and the checks after the reconnect succeed.

Test setup

The profile used the chain of the VLESS + TLS scenario, with the same server copy and profile settings, except the options the steps above change.

Gaps and limits

  • The phone did not really sleep, and WaterWall inside the app did not really crash: a Debug build of the app accepts test commands that make the tunnel act as if it had. Stopping the server is real.
  • Each step ran once, on one phone and one network.
