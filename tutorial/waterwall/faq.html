FAQ

Short answers, with links to the pages that explain more.

Setting up

Is there an Android version?

Yes, with the same WaterWall screens and options as on iPhone. It has WaterWall only so far and it is not in a store yet, so you build the APK yourself. We tested it on a Samsung Galaxy A55 and on the Android emulator. See Android.

Do I need to install WaterWall on my phone?

No. SRP VPN Connect contains its own WaterWall client. You only install WaterWall on your server; see Installation.

Which WaterWall versions does this guide cover?

The official WaterWall 1.5.42 release on the server, and the iPhone and Android apps, which contain their own WaterWall built from 1.5.42. Results with other server programs are not covered. See Versions we tested.

Do I need a domain name and a certificate?

For chains with Outer TLS or QUIC, yes: the server needs a certificate, and with TLS Server Verification on (the default) it must be valid for the name the app sends. Our server uses a free Let's Encrypt certificate. Outer Reality and AEAD do not use a certificate of your own.

Which chain should I start with?

Getting Started walks through VLESS + TLS, the app's default chain, step by step.

Can I import a vless:// link or a QR code?

No. The tested build has no import or export for WaterWall profiles: you enter each profile by hand. The only imports are a WireGuard .conf file in WireGuard mode and a GeoIP country database.

Can I use the app with an Xray or V2Ray server?

We only tested the app with WaterWall servers, so that is not verified. Note that WaterWall's MUX is its own format and is not V2Ray's Mux.Cool or XUDP.

Using the app

Why does the profile row say Ping: —?

No delay has been measured for that profile yet. Pull the list down to ping every profile, or swipe a row to the right and tap Ping. See How ping is measured.

Why can't the app ping my KCP or QUIC profile?

The ping before connecting measures a TCP handshake, and KCP, QUIC Datagram, Direct and WireGuard profiles do not reach the server over TCP. The app says so instead of showing a result. Connect to the profile to see its delay.

Where can I see what went wrong?

Tap the status text under the power button to open the app's log. Set Log Level to Expert or Debug in the profile's OPTIONS for more detail, then connect again.

Does the tunnel carry IPv6?

No. The WaterWall tunnel carries IPv4 only. On Android, apps also get no IPv6 route while the VPN is up, so IPv6 traffic does not leave outside the tunnel.

Does traffic to the server itself go through the tunnel?

On iPhone, with Raw IPv4 input or WireGuard, no. The app keeps the server's own address out of the tunnel, so a speed test or a site on that same address goes straight there over your normal network, and shows that network's speed. With Connections input and Remote DNS (Fake IP) on, it goes through the tunnel. On Android it always goes through the tunnel.

Does the app support Fake TCP (FakeTcpHeaderClient)?

No, and a phone cannot run it without root. Fake TCP sends IP packets with a made-up TCP header directly onto the network, which needs a raw socket. iOS refuses a raw socket both in the app and in its VPN extension, and Android refuses it to an ordinary app: in our test each attempt ended with Operation not permitted or Permission denied. A VPN tunnel's packets only reach the phone's own system, so they cannot replace this.

What is Packet Encryption, and when should I use it?

It is WaterWall's packet mode encryption for Raw IPv4 chains: each packet's TCP or UDP payload is encrypted separately with XChaCha20-Poly1305, adding 40 bytes per packet. The IP and TCP or UDP headers stay readable to anyone who can see inside the chain, and only TCP and UDP pass, so ping (ICMP) does not work through it. It helps when the chain has no other encryption, such as Outer None or BGP4. If you can choose, Outer AEAD or TLS hide the whole stream. See the Configuration Reference.

Is the Obfuscator a kind of encryption?

No. It scrambles bytes with a fixed XOR key so they show no obvious pattern. Anyone who knows the method can undo it. BGP4 framing does not encrypt either. Use TLS, Reality, AEAD, QUIC or VMess for encryption.

What does Remote DNS (Fake IP) do?

When an app on the phone looks up a name, the tunnel answers at once with a placeholder address from 100.64.0.0/10 and sends the name itself to the server, which looks up the real address. This keeps your DNS lookups inside the tunnel. When it is off, the phone asks 1.1.1.1 and 1.0.0.1.

What does Auto Switch do, and why does nothing happen?

Auto Switch uses your other WaterWall Chain profiles with the same Server as fallbacks. With only one profile for that server there is nothing to switch to. The option appears only in Chain mode. See OPTIONS.

What happens when the phone sleeps?

That depends on On Sleep: Stay (the default) keeps the connection, Pause closes it and reconnects on wake, and Off closes it and reconnects on wake only when Auto Reconnect is on. On Android, sleeping means the screen going off.

What sizes does TLS Fragmentation Auto use?

Auto cuts the ClientHello after 32 bytes and then every 256 bytes. Choose Manual to set your own sizes; the First Chunk must be smaller than 16384 bytes.

What should I type in SNI for Reality?

The name of the cover site your Reality server passes visitors to. Left empty, the app uses www.cloudflare.com, the cover our server uses.

Server side

What must match between the app and the server?

The layers, in the same order, on the same port, and the values listed in The server node for each app choice: for example the UUID, the Reality password and salt, or the HTTP path.

Can one server run several chains?

Yes. Each chain is its own file on its own port, and all of them are listed in core.json. Our test server runs 44 of them. See Configuration Reference.
