Future Protocols

SRP VPN Connect supports more protocols than these guides cover. A protocol gets its own section only after we have tested it on our own servers and reviewed the results.

What each new section will contain

Each new protocol gets the same parts as WaterWall, SSTP, SoftEther VPN, SSL VPN and SSH VPN:

  • How to build and run the server.
  • How to set up the app.
  • A configuration reference: the server settings that matter to the app, and what each profile field does.
  • Security, addresses, routing and DNS.
  • The scenarios we tested, each with its result.
  • How to check the connection.
  • Troubleshooting.
