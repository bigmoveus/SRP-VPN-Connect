SoftEther VPN

SoftEther VPN is the native protocol of SoftEther VPN Server: a virtual Ethernet carried inside TLS, usually on TCP port 443. SRP VPN Connect connects to it on iPhone and Android with the same SoftEther client core on both.

How a SoftEther connection works

  1. TCP and TLS. The app opens a TCP connection to the server, directly or through a proxy, and starts TLS. With TLS Server Verification on, it checks the server's certificate against the server's name, or against Hostname when that is set.
  2. Login. Inside TLS the app names the Virtual Hub and logs in as a user of that hub, with a password, through the server's RADIUS server, with a client certificate, or anonymously.
  3. More connections. When the profile asks for more than one, the app opens further TCP connections for the same session, up to 32.
  4. UDP. With UDP acceleration on, the app and the server also exchange the VPN's packets over UDP. With NAT traversal on, the app can reach a server that has no open TCP port through the NAT-T servers of SoftEther Corporation.
  5. Addresses. The session is a virtual Ethernet cable into the hub. The app asks the hub for an address with DHCP, for example from the hub's SecureNAT, and all of the phone's IPv4 traffic then goes through the tunnel.

Where to start

  1. Set up the server: SoftEther VPN Server builds SoftEther VPN Server 4.44 on Ubuntu and sets it up from the command line, with a user for every login method.
  2. Install the app: on iPhone from TestFlight, on Android by building it from the source; see Installation. Our tests ran the app built from commit 013f04fb on both phones; on iPhone the log cases ran again with commit 7708f7a3, as a Release build like TestFlight's. On iPhone use TestFlight build 36 (commit 868a4df1) or later: build 35 is older than these commits and lacks their SoftEther changes.
  3. Add a SoftEther VPN profile: Setting up the app.
  4. The server settings that matter to the app, and what each profile field does: Configuration Reference.
  5. If it does not connect: Troubleshooting.

What was tested

Test results lists every case we ran against our SoftEther VPN Server 4.44, with its result on an iPhone and on an Android phone: every login method and the refusals, the Virtual Hub, Hostname and the certificate check, the ports, 1 to 32 connections, UDP acceleration, NAT traversal with and without a hint, HTTP and SOCKS5 proxies and PAC files, TLS Fragmentation, the log levels, and what happens on sleep, when the server ends the session, when it is away for a while and when Retry Times runs out.
