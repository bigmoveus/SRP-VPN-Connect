SSTP

SSTP (Secure Socket Tunneling Protocol) carries a VPN connection inside HTTPS on port 443.

Status: guides not written yet The SSTP section is phase 2 of this documentation and starts once the WaterWall section is complete.

What the SSTP section will cover

We have already built and tested real SSTP servers with three different server products:

  • MikroTik RouterOS
  • Windows Server 2019, 2022 and 2025 with Routing and Remote Access (RRAS) and Network Policy Server (NPS)
  • SoftEther VPN Server 4.44, with a FreeRADIUS server for RADIUS logins

The section will explain how SSTP works, how each of these servers was set up from scratch, certificates and TLS, users and RADIUS, addresses, routing, DNS and firewall rules, the app's SSTP settings, and every scenario we tested, including the ones that failed. Until those pages exist, nothing on this site should be read as an SSTP guide.
